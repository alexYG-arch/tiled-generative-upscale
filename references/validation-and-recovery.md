# 校验与恢复

## 1. 规划通过才开始批量生成

记录原图尺寸、宽高倍率、目标尺寸和试生成测得的原生容量。分析 JSON 至少包含：

- `summary`、`style`、`palette`：图像内容、表现方式与色调约束。
- `materials`：材质名称到统一细节提示词的字典；同种材质不得各块临时改写。
- `regions`：各区域的 `id`、`box`、`kind`、`material`、`object`、`seam_avoid`、`detail`。

查看原图后再标记文字、标志、人物、完整物体、建筑直线、细长结构、重复纹理和留白。检查所有切片、重叠区和跨块对象；切片大小必须受实际可用原生输出约束。移开接缝后重新计算数量与覆盖，不能只修改图上的网格。

先生成代表性材质及相邻块试样，验证细节密度、画幅、颜色和接缝，再启动剩余队列。试样输出不是工具以后必然返回相同尺寸的保证，后续每块仍要检查。

## 2. 每块分别登记、分别查看

`register` 保存本次工具回执并复制原始生成图；它不应拉伸图像，也不意味着视觉通过。登记后必须检查：

| 项目 | 通过条件 | 不通过时 |
| --- | --- | --- |
| 原生尺寸 | 实际解码尺寸与记录一致；有效 crop 两边都不少于目标块尺寸 | 重试生成或重新规划更小切片；禁止用插值补足 |
| 画幅与落位 | 有效 crop 的比例与目标块相差不超过 0.5%；保留目标所需全部内容 | 拒绝各向异性拉伸；重试，或有视觉证据地指定 crop 后重新检查 |
| 内容与构图 | 物体位置、数量、轮廓和透视符合原图；没有新增主体、重复物体、裁切缺失 | 修订该块提示词，重新生成；必要时连同相邻块处理 |
| 文字与标志 | 没有错字、伪字、断笔、替换标志和虚构小字 | 重试；不能把“看着像文字”判为通过，也不能猜写不可辨的小字 |
| 材质与颜色 | 同一对象的纹理尺度一致，色调与原图及已验收邻块一致 | 按共享材质词典修订，不独立换风格 |
| 边界 | 跨块的线条、叶脉、笔触和建筑边缘连续，无重影、断裂或明显色阶 | 局部再生成，扩大上下文或重新切分后检查 |

通过 `review` 记录实际看见的结果、采用的 crop 及问题结论，才允许进入 `qa_passed`。接触表用于总览，不能替代文字、复杂结构和接缝处的 100% 查看。失败记录和原始尝试应保留，不能覆盖成一条成功记录。

## 3. 机械拼合与人工视觉验收分开

全部计划块通过后运行 `python scripts/compose.py RUN_DIR`。该脚本只执行经审核的 crop、尺寸归一、坐标落位和重叠羽化：

- 两边均禁止放大；比例容差仅供像素取整，不允许大幅改变形状。
- 不自动添加仿射、光流、背景替换、文字覆盖或全图再次放大。
- 使用 premultiplied alpha；透明像素仍是有效的几何覆盖。
- 真实检查全画布权重；存在缺口即停止，不用 epsilon 隐藏缺口。
- 写出 RGBA、sRGB 的 `composite.png`、缩小的 `preview.jpg` 和 `compose_report.json`。
- 写出 `seam_reviews/index.json` 与全部邻接区域的 100% JPG；每段最长边不超过 1500 像素。透明部分仅在 JPG 预览中显示棋盘背景。

检查报告中的实际解码尺寸、覆盖像素、每块原生尺寸/crop 和接缝索引。机械报告中的 `visual_acceptance: pending` 必须保留至真实查看完成。

按索引逐段检查全部接缝，并检查整图布局、颜色、文字和关键细节。JPG 接缝图尺寸与目标像素一一对应；浏览器或查看器缩小显示时，仍需进入 100% 查看。不能只看缩小整图便判定无缝。

最后由 `finish` 检查全部接缝审核记录和交付条件。交付至少包括最终图、预览、尺寸与验收记录；保留可追溯的原始生成图和提示词。若文字、标志或留白另行采用原图保护，必须明确保护区域、处理方式与验收结果；本机械拼合脚本不自动实现该后处理，也不能把保护区描述为新生细节。

## 4. 失败后的恢复

先用 `status` 查实际进度；成功登记和审核的块可以复用。暂停或失败不应重新初始化计划、覆盖原始生成图或抹去已完成状态。

| 问题 | 恢复动作 |
| --- | --- |
| 工具调用失败或未返回可用图像 | 保存失败原因；按本次计划的重试上限继续，不能无限重试或伪造成功回执 |
| 输出尺寸/画幅持续不满足 | 按测得容量缩小裁切并更新计划、覆盖与运行顺序；已改变范围的块重新生成和审核 |
| 个别块内容错误 | 只修订相关提示词及受影响邻块，保留前一次尝试 |
| 多块同一材质偏色或细节不同 | 修订共享规则后统一处理受影响块，不分别随意校色掩盖问题 |
| 有接缝、重影或直线弯曲 | 返回相关块和相邻上下文修复；不能仅增加模糊或启用未审核的光流 |
| 缺文件、状态不合格、画布缺口 | 修正计划或补齐正确输出，再重新审核；不要降低门禁以完成导出 |
| 已有导出需要修订 | 将自己旧导出归档，或使用新的运行目录；拼合脚本拒绝覆写现有导出 |
| 中断后 attempt 文件已存在但状态未登记 | 对照原始工具回执、文件和 prompt，先归档这次未登记的副本，再登记原始输出；保留证据，不删除已成功状态，也不要再次调用生图来解决登记问题 |
| 磁盘不足 | 保留源图、原始尝试与状态，清理自己可再生的临时产物或更换输出位置后恢复 |

明确区分：文件已生成、单块已通过、机械拼合完成、全图视觉通过、交付完成。任何一项未完成，都不应报告为最终完成。
